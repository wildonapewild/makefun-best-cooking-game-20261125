# Warteg Bahari Express — Indonesian Buffet Stall

A fast lunch-rush cooking game set in a clean, modern Warung Tegal (warteg).
Customers pin tickets to the order board: one rice size (biasa or jumbo),
exactly 3 dishes scooped from the glass display case (4 dishes once the rush
deepens), spoonfuls of sambal, and kerupuk crackers. Scoop portions from the
six steel trays — ayam goreng, rendang sapi, telur balado, tempe orek, sayur
lodeh, ikan tongkol — but watch the stock bars: trays run dry, and an empty
tray must go back to the wide wok, where a reheating timer cooks a fresh
batch. Serve a plate that matches its ticket exactly to earn rupiah plus a
patience bonus; let three customers walk away and the shift fails.

## How to play

- Click a tray (or press 1–6) to scoop that dish onto the plate.
- R = nasi biasa, J = nasi jumbo, S = sambal spoon, K = kerupuk.
- Click a dry/critical tray (or press W) to send it to the reheating wok.
- Space / Enter (or the SAJIKAN button) serves the front ticket; the plate
  must match the ticket exactly — rice, dish set, sambal count, kerupuk.
- Backspace throws the plate away and starts a fresh one.
- Survive the 3-minute shift clock; patience bars and strikes end the run.

All artwork is drawn in code on a 1280×800 canvas (green ceramic tiles,
steel counters, glass case) — no external assets. Deterministic screenshot
scenes: `?shot=cover|rush|serve&seed=N`.
